# 火山引擎报价单生成

根据客户给出的「地域 + 产品 + 配置（+ 数量）」，匹配火山引擎官方配置，读取**官方采购界面的实际价格**，按内部报价模板输出 `.xlsx` 报价单。

## 触发条件

- 用户给出地域/产品/配置要求报价，例如：
  `地域：北京；产品：云服务器，配置：4核8G，系统盘40G，数据盘100G，带宽5M，数量1台`
  `数据库 SQL Server 2019 标准版 2核4G 存储200G`
- 用户要求「火山引擎报价单」「出个报价」「按模板报价」

## 一、硬性口径（每次都必须遵守）

1. **配置列 = 官网页面上每一个需要选择/填写的项**，逐项写成 `字段名：值`，**同一个单元格内换行**（`\n` + `wrapText=True`）。缺项＝不合格。
2. **价格口径**（必须有公式，便于追溯）：
   - `官网刊例价/年` = 采购界面的 **配置费用**
   - `官网目录价/年` = **配置费用 + 已省费用**，模板里写成公式 `=<配置费用>+<已省费用>`
   - 总计行 = 各产品行求和 `=SUM(...)`；总计行沿用模板备注
3. **价格必须来自官方采购界面/价格计算器的真实数字**，禁止估算、禁止按规格线性折算、禁止编造。未登录状态下定价页通常仍显示价格。
4. **产品行「备注」留空**。
5. 多个产品各占一行；单产品时总计 = 该行。

## 二、取价流程

1. 打开官方定价页的「价格计算器」：`https://www.volcengine.com/pricing?product=<产品>&tab=2`
   - 产品参数示例：`ECS`、`EIP`、`RDS+for+MySQL`、`RDS_for_SQL_Server`
2. 在页面上**选择客户给定的每一项配置**（地域 / 计费类型 / 版本 / 实例类型 / 规格类型 / 规格 / 存储类型 / 存储大小 / 时长），读取右侧：
   - **配置费用**（部分页显示为「预估费用」）
   - **已省**
3. 交叉核对：官方文档「计费项与价格」页会给出单价与折扣，可用于复核（见文末链接）。
4. 用浏览器读取（页面上「官网优惠价/官网刊例价」开关可切到刊例口径核对单价；`tab=2` 内既有「定价详情」表也有「价格计算器」）。

> 常见坑：定价页有「官网优惠价 / 官网刊例价」切换，**默认是优惠价**；本报价取优惠价口径（配置费用），目录价用「配置费用 + 已省」反推。

## 三、生成流程

1. 定位内部报价模板 xlsx（用户提供的「报价参考」文件，通常在上传目录 `/workspace/.uploads/`）。模板列：`序号 | 产品 | 地域 | 配置 | 官网目录价/年 | 官网刊例价/年 | 备注`。
2. 写 `spec.json`（格式见 `scripts/build_quote.py` 头部注释），运行：

```bash
python3 -m pip install openpyxl            # 若未安装
python3 .trae/skills/volcengine-quote/scripts/build_quote.py spec.json
```

3. `build_quote.py` 会：复制模板 → 只保留标题/报价时间/表头 → 写入产品行与总计行 → 保留模板样式/合并/字体/数字格式 → 给公式注入缓存值（便于未重算环境直接显示）。
4. 交付时用 `computer://` 链接给出文件，并列出：报价表、计价依据（单价×数量×折扣）、以及口径说明。

## 四、各产品采购界面配置项（抄录全部项）

> 页面字段会调整，下单前以实际页面为准。

| 产品 | 定价页 | 需要抄录的配置项 |
|---|---|---|
| 云服务器 ECS | `pricing?product=ECS&tab=2` | 计费类型、地域、可用区、规格族、实例规格、镜像、系统盘（类型+容量）、数据盘（类型+容量）、公网IP 带宽、数量 |
| 公网 IP EIP | `pricing?product=EIP&tab=2` | 计费类型、地域、线路类型（BGP多线）、带宽上限、数量 |
| 云数据库 MySQL | `pricing?product=RDS+for+MySQL&tab=2` | 计费类型、地域、兼容版本、引擎类型、实例类型（双节点/单节点）、规格类型（通用规格/独享规格）、节点规格、存储类型、存储空间、数量 |
| 云数据库 SQL Server | `pricing?product=RDS_for_SQL_Server&tab=2` | 计费类型、地域、兼容版本、实例类型（高可用版/基础版）、规格类型（通用型/通用Ⅱ型/独享型/独享Ⅱ型）、节点规格、存储类型、存储空间、数量 |
| 云数据库 veDB MySQL | `pricing?product=veDB+MySQL&tab=2` | 计费类型、地域、实例类型、节点规格、节点数量、存储空间、数量 |

要点：
- RDS 系列「节点规格」写「主节点 <核数>（规格代码）」，**规格代码必须写全**（如 `rds.mysql.d1.n.4c8g`）。
- 规格代码里 `.se.`=标准版、`.ee.`=企业版、`.ha.`=高可用版、`.std.`=基础版（SQL Server 命名规律）。
- 多存储类型时按客户要求选；客户没指定就用采购页默认那档。

## 五、内部模板结构（用于核对）

- 第 1 行：标题（合并 `A1:G1`）
- 第 2 行：`报价时间` + `=TODAY()`
- 第 3 行：表头 `序号 | 产品 | 地域 | 配置 | 官网目录价/年 | 官网刊例价/年 | 备注`
- 第 4 行起：产品行
- 末行：`总计`（合并 `A:D`），E/F 为 `=SUM(...)`
- 正文字体 宋体 12pt；价格 `"￥"#,##0.00`；配置列自动换行

## 六、工具使用要点（避免踩坑）

- **openpyxl 可能未安装**：`python3 -m pip install openpyxl`（需要的网络代理按环境变量走）。
- **MergedCell 不能赋值**：先 `ws.unmerge_cells(...)` 再写值，最后重新 `merge_cells`。
- **Style 对象不可变**：`from copy import copy`，`copy(cell.alignment)` 后再改属性并重新赋值。
- **公式缓存**：openpyxl 保存后公式只剩 `<f>` 没有 `<v>`，在未重算的预览器里会显示空白。用 `build_quote.py` 自动注入缓存，或手工改 `xl/worksheets/sheet1.xml`。
- **无 `soffice` 时无法重算公式**，因此公式 + 缓存值必须成对写入。
- 行高按配置行数估算：`行数 × 字号 × 1.45`（宋体 12pt 约 17.5 磅/行）；总计行约 35。
- **安装火山引擎官方 CLI/技能（可选）**：`npx -y @volcengine/skills-setup@latest`。若 Node 的 `https.get` 不读系统代理导致下载失败，可手动下载 `volcengine-cli_<ver>_linux_amd64.zip` 解压 `ve` 到 PATH，再 `ve skills update`。

## 七、交付前校验清单

- [ ] 配置列逐项齐全，且单元格内换行
- [ ] `官网目录价 = 配置费用 + 已省费用`（E 为公式）
- [ ] `官网刊例价 = 配置费用`
- [ ] 总计行 = SUM，产品行备注为空
- [ ] 数字格式 `"￥"#,##0.00`，样式与模板一致
- [ ] 公式单元格已注入缓存值（打开即显示，无 `#REF!`/空白）
